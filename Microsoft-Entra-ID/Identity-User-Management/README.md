# Microsoft Entra ID — Identity & User Management

## Overview

This project demonstrates hands-on administration of cloud identities
using Microsoft Entra ID and the Microsoft 365 Admin Center.

The lab covered the complete process of creating a Microsoft Entra user,
configuring identity properties, assigning group membership, reviewing
administrative roles, assigning a Microsoft product licence, and
validating the user through a successful first sign-in.

The project demonstrates fundamental Identity and Access Management
(IAM) concepts used in Microsoft cloud environments.

---

## Objectives

The objectives of this project were to:

- Create a new Microsoft Entra ID user
- Configure user identity properties
- Configure the user's usage location
- Understand Member and Guest identity types
- Assign the user to a security group
- Review Microsoft Entra administrative roles
- Apply least-privilege principles
- Assign an available Microsoft product licence
- Validate the user's first successful sign-in

---

## Technologies Used

- Microsoft Entra ID
- Microsoft 365 Admin Center
- Microsoft 365
- Microsoft Entra Security Groups
- Identity and Access Management (IAM)
- Microsoft Authentication

---

## Environment

The lab was completed in a Microsoft cloud tenant using administrative
access to Microsoft Entra ID and the Microsoft 365 Admin Center.

A dedicated test identity was used so that user provisioning,
group assignment, licensing, and authentication could be safely tested.
