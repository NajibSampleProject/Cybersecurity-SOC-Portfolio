# Microsoft Purview – Sensitivity Labels & Information Protection

## Project Overview
Hands-on Microsoft Purview security lab exploring data classification, sensitivity labels, information protection policies, and automated labeling within a Microsoft 365 training environment.

## Technologies
- Microsoft Purview
- Microsoft 365
- Microsoft Information Protection
- Exchange Online
- Sensitivity Labels
- Data Classification and Governance

## Lab Activities
1. Explored Microsoft Purview Information Protection.
2. Reviewed the preconfigured Highly Confidential sensitivity label.
3. Examined access controls, content marking, and credit card detection settings.
4. Reviewed the Highly Confidential label publishing policy.
5. Explored user and group assignments and policy settings.
6. Walked through an auto-labeling policy configuration using a medical and health information template.
7. Reviewed Exchange email protection and policy conditions.

## Security Skills Demonstrated
- Data classification and protection
- Sensitivity label management
- Access control concepts
- Information governance
- Sensitive information detection
- Microsoft 365 security administration
