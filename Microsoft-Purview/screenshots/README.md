# Microsoft Service Trust Portal & Trust Center Lab

## Overview

This hands-on lab focused on exploring the Microsoft Service Trust Portal and Microsoft Trust Center to understand how Microsoft communicates its approach to security, privacy, compliance, regulatory standards, and Responsible AI.

The lab also provided practical experience with accessing compliance documentation, reviewing ISO/IEC resources, saving reports to a personal library, and exploring industry-specific compliance information.


## Objectives

During this lab, I:

- Explored the Microsoft Service Trust Portal
- Reviewed ISO/IEC compliance documentation
- Used document options available within the portal
- Saved compliance documents to My Library
- Reviewed subscription and notification settings
- Explored industry and regional compliance resources
- Reviewed organisation-specific resources
- Explored the Microsoft Trust Center
- Reviewed Microsoft's approach to privacy, security, and compliance
- Explored Microsoft's Responsible AI resources

### Security and Compliance Relevance

This lab helped me understand that cybersecurity is not only about detecting threats and responding to incidents.

Security professionals also need to understand:
- Regulatory requirements
- Compliance frameworks
- Data protection
- Privacy
- Security assurance
- Governance
- Industry standards
- Audit and certification evidence

The Microsoft Service Trust Portal provides organisations with documentation that can support security reviews, compliance assessments, audits, and risk-management activities.

### Key Learning:

My main takeaway from this lab was understanding the importance of trust and assurance in cloud security.

A cloud provider must not only provide technical security controls but also demonstrate how those controls align with recognised standards, regulations, and compliance requirements.

A simplified way to think about it is:

Security Controls → Evidence → Compliance → Trust

The Service Trust Portal provides the evidence and documentation organisations can use to understand how Microsoft protects its cloud services and customer data.
