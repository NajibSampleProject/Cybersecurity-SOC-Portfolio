# Microsoft Purview Compliance Manager Lab

## Overview

This hands-on lab focused on exploring Microsoft Purview and Microsoft Compliance Manager to understand how organisations can monitor, assess, and improve their compliance posture.

The lab provided practical exposure to compliance scoring, improvement actions, assessments, regulations, policies, and compliance alerts within Microsoft Purview.

## Objectives

During this lab, I explored and worked with:
- Microsoft Purview portal
- Compliance Manager
- Compliance Score
- Improvement Actions
- Compliance Solutions
- Assessments
- Data Protection Baseline for Microsoft 365
- Regulations
- Compliance Policies
- Compliance Alerts

### Security and Compliance Relevance

This lab helped me understand that cybersecurity involves more than threat detection and incident response.

Organisations also need to understand whether their security and data-management practices align with regulatory requirements, internal policies, and recognised compliance frameworks.

Microsoft Compliance Manager helps organisations:

- Measure compliance posture
- Identify areas requiring improvement
- Track recommended actions
- Assess controls
- Review regulatory requirements
- Monitor compliance-related events
- Prioritise remediation activities

A simplified workflow is:

Assess → Identify Gaps → Improve Controls → Monitor → Maintain Compliance

### Key Learning 

My key takeaway from this lab was that compliance is an ongoing process rather than a one-time activity.

Compliance Manager provides organisations with a structured way to identify gaps, prioritise improvements, track progress, and understand how technical and organisational controls contribute to their overall compliance posture.

The relationship can be simplified as:

Controls → Assessment → Improvement Actions → Compliance Score → Stronger Compliance Posture
