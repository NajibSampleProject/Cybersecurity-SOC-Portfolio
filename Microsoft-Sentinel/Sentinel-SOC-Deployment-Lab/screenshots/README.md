
# Microsoft Sentinel — SIEM Deployment & SOC Fundamentals Lab

## Overview

A guided hands-on Microsoft Sentinel lab completed
in an authorised Microsoft training environment.

The project focuses on SIEM deployment, cloud
security data integration, analytics-rule configuration,
access-control review, and exploration of SOC workflows.

## Technologies

- Microsoft Sentinel
- Azure Log Analytics
- Microsoft Defender for Cloud
- Azure Role-Based Access Control (RBAC)
- Microsoft Sentinel Content Hub
- Analytics Rules
- MITRE ATT&CK

## Objectives

1. Create a Log Analytics workspace.
2. Enable Microsoft Sentinel for the workspace.
3. Review Microsoft Sentinel permissions and RBAC roles.
4. Install the Microsoft Defender for Cloud solution.
5. Configure the available Defender for Cloud connector.
6. Review and configure an analytics rule.
7. Explore incident management, hunting and automation.

## Lab Implementation

### 1. Log Analytics Workspace

Created a resource group and Log Analytics workspace
as the foundation for Microsoft Sentinel.


### 2. Microsoft Sentinel

Enabled Microsoft Sentinel for the lab workspace.


### 3. Access Control

Reviewed IAM access and built-in Microsoft Sentinel
roles to understand least-privilege administration.


### 4. Content Hub

Explored Content Hub and installed the Microsoft
Defender for Cloud solution.


### 5. Data Connector

Reviewed the Defender for Cloud connector and its
configuration status.


### 6. Analytics Rule

Explored the analytics rule:
"Detect CoreBackUp Deletion Activity from related
security alerts".

Document whether the rule was successfully saved
and verified in the active rules list.

### 7. SOC Capabilities

Explored the Incidents, Hunting, Threat Intelligence,
MITRE ATT&CK, Analytics, and Automation interfaces.



## Security Analysis

This lab introduces how a SIEM platform can
centralise security information and support
detection and investigation workflows.

Key concepts explored:

- Security data onboarding
- Access control and least privilege
- Analytics-based detection
- Incident management interfaces
- Threat hunting capabilities
- MITRE ATT&CK mapping
- Security orchestration and automation
