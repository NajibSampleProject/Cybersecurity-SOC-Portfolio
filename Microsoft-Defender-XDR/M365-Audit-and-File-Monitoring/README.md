## Lab Evidence

Microsoft 365 Audit Logging & File Monitoring Lab

Overview

This hands-on lab focused on configuring security monitoring capabilities within a Microsoft 365 training tenant.

The objective was to:

Enable Microsoft 365 audit logging

Record user and administrator activity

Enable file monitoring through Microsoft Defender

Improve visibility for security monitoring and investigations
